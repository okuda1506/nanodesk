# NanoDesk

[English](README.md) · [日本語](README.ja.md) · 한국어

NanoDesk는 은색 5세대 iPod nano를 조작할 수 있는 3D 모델로 Mac 데스크탑에 표시하는 앱입니다. 일본어 메뉴에서 Music 앱의 곡을 재생하고, Cover Flow로 앨범을 찾아보고, Mac 카메라로 동영상을 촬영할 수 있습니다.

## Mac에 설치

macOS 15 이상이 설치된 Apple Silicon Mac, Git, Xcode 16 이상이 필요합니다. Xcode를 설치하고 한 번 실행하여 초기 설정을 완료하세요.

```bash
git clone https://github.com/okuda1506/nanodesk.git
cd nanodesk
./scripts/install-macos.sh
```

스크립트가 Release 버전을 빌드하고 로컬 서명한 뒤 `~/Applications/NanoDesk.app`에 설치하고 실행합니다. 다시 실행하려면 Finder에서 홈 폴더의 **응용 프로그램**을 열고 **NanoDesk**를 이중 클릭하세요. 앱은 메뉴 막대의 **NanoDesk** 메뉴에서 제어할 수 있습니다. 업데이트할 때는 NanoDesk를 종료하고 기존 앱을 다른 곳으로 옮긴 뒤, 업데이트한 저장소에서 스크립트를 다시 실행하세요.

## 기본 조작

| 동작 | 방법 |
|---|---|
| 탐색 및 선택 | 클릭 휠을 따라 드래그하여 스크롤하고 가운데 버튼으로 선택합니다. **MENU**를 누르면 이전 화면으로 돌아갑니다. |
| 회전 및 이동 | 본체를 드래그하여 회전하고 Option을 누른 채 드래그하여 이동합니다. 본체를 이중 클릭하거나 **Reset Orientation**을 선택하면 정면을 향합니다. |
| 크기 조절 | 핀치, Command를 누른 채 스크롤, 또는 **Increase Size**, **Decrease Size**, **Reset Size**를 사용합니다. |
| 데스크탑 표시 관리 | 메뉴 막대에서 표시와 숨기기, 위치 초기화, **Always on Top**, **Click Through**, 종료를 제어합니다. 기기를 조작하려면 **Click Through**를 끄세요. |
| 홀드 | 기기를 돌려 상단의 홀드 스위치를 클릭합니다. 주황색 표시가 보이면 휠 조작과 회전을 통한 Cover Flow 전환이 잠깁니다. 음악은 계속 재생됩니다. 다시 클릭하면 잠금이 풀립니다. |

## 음악 재생

**ミュージック**(음악) → **曲**(곡)을 열고 macOS 알림에서 NanoDesk의 Music 제어를 허용하세요. Music 앱 보관함에서 재생할 수 있는 곡을 고르고 가운데 버튼을 누르면 **再生中**(재생 중) 화면이 열립니다. 현재 재생 중인 곡을 선택하면 재생 위치가 유지됩니다. 휠 아래쪽은 재생·일시 정지, 왼쪽과 오른쪽은 이전·다음 곡입니다. 목록을 탐색하는 중에도 사용할 수 있습니다. 권한을 거부했다면 **시스템 설정 → 개인정보 보호 및 보안 → 자동화 → NanoDesk**에서 Music을 허용한 뒤 **曲**을 다시 여세요.

## Cover Flow로 앨범 탐색

홈, 음악, 곡 목록 또는 재생 중 화면에서 두 손가락으로 돌리거나 Command를 누른 채 드래그하여 기기를 가로로 돌립니다. **ミュージック → Cover Flow**로도 열 수 있습니다. 휠로 아티스트순으로 앨범을 탐색하고, 휠을 빠르게 움직여 첫 글자 단위로 이동합니다. 가운데 버튼으로 앨범을 연 뒤 곡을 고르고 다시 누르면 재생됩니다. 기기를 세로로 돌리면 돌아갑니다.

## 동영상 촬영

홈 메뉴에서 **ビデオカメラ**(비디오 카메라)를 선택하고 카메라 접근을 허용하세요. 소리를 녹음하려면 마이크 접근도 허용하세요. 가운데 버튼을 누르면 빨간 점과 타이머가 표시되며 녹화가 시작됩니다. 다시 누르면 녹화를 멈추고 저장합니다. **MENU**로 홈으로 돌아갈 때도 촬영 중인 동영상을 마무리하여 저장합니다.

NanoDesk 메뉴에서 **Open Camera Roll in Finder**를 선택하면 동영상 폴더의 **NanoDesk/Camera Roll**을 열 수 있습니다. 동영상은 640 × 480, 목표 30 fps의 H.264 MP4로 저장됩니다. 마이크를 사용할 수 있으면 AAC 오디오가 포함됩니다. 세로 미리보기는 좌우 반전되며, 저장한 가로 영상은 좌우 반전되지 않습니다.

NanoDesk는 Apple의 공식 승인을 받지 않은 팬 프로젝트입니다.
